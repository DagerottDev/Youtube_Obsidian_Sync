## Local statistics update — 2026-10-06

At the time of this update, the statistics implementation was local and unreleased, and the
public release was 0.3.3. The copy below records the upcoming-update announcement from October 6.

### Forum update copy

Coming in the next update: **Your statistics**, a new section in the plugin settings.

It shows your current collection — configured playlists, video notes, notes with transcripts,
and notes with AI summaries — plus activity recorded from when the feature first loads:
playlists added, notes created, transcripts saved, summaries generated, and successful or failed
sync runs. Current totals scan only the configured plugin folder and its subfolders.

Recording is on by default and stays entirely local. You can pause recording, refresh collection
totals, or reset the activity counters without changing your notes. Existing notes contribute to
current totals, but past activity is not reconstructed.

There is also a JSON report you can preview and manually copy if you choose to share it. It
contains aggregate counts and recording/scan dates, with no note content, titles, URLs, paths,
credentials, or user identifiers. Nothing is uploaded automatically, and there are no analytics
services or new network calls.

This feature is implemented but **not yet in the published 0.3.3 release**. Desktop controls have
been checked; testing on an actual mobile device is still pending. I’d welcome feedback on which
counts would be useful for your learning or research workflow.

> Status: the publisher ended the Obsidian Roundup in its former format in 2023, so there is no

> YouTube Playlist Sync turns any public YouTube playlist into a searchable Obsidian knowledge
> base. It creates one note per video with title, channel, URLs, IDs, thumbnail, description,
> upload date, category, duration, keywords, and a transcript when captions are available. It
> also maintains playlist and root index notes, performs incremental syncs without overwriting
> user edits, and supports desktop plus mobile. No YouTube API key is required. AI summaries are
> optional and can use OpenAI, NVIDIA NIM, or another OpenAI-compatible endpoint. Install:
> <https://obsidian.md/plugins?id=youtube-playlist-sync>
