### Forum announcement

> Disclosure: I'm the developer of YouTube Playlist Sync, an Obsidian community plugin for turning
> public YouTube playlists into searchable video notes. It adds video metadata, captures transcripts
> when captions are available, maintains playlist/root indexes, and later syncs add new videos
> without overwriting existing note edits. Normal playlist syncing needs no YouTube API key; AI
> summaries are optional and use a provider you configure. The latest published release is 0.3.2.
> Install: <https://obsidian.md/plugins?id=youtube-playlist-sync>

### Obsidian Roundup submission (archived — do not submit)

> Status: the publisher ended the Obsidian Roundup in its former format in 2023, so there is no
> active submission path. This copy is retained only as reusable plugin-description text.
> Source: [publisher update](https://www.eleanorkonik.com/p/state-of-the-eleanor-03).

> YouTube Playlist Sync turns any public YouTube playlist into a searchable Obsidian knowledge
> base. It creates one note per video with title, channel, URLs, IDs, thumbnail, description,
> upload date, category, duration, keywords, and a transcript when captions are available. It
> also maintains playlist and root index notes, performs incremental syncs without overwriting
> user edits, and supports desktop plus mobile. No YouTube API key is required. AI summaries are
> optional and can use OpenAI, NVIDIA NIM, or another OpenAI-compatible endpoint. Install:
> <https://obsidian.md/plugins?id=youtube-playlist-sync>
