### Reddit workflow post

**Title:** I turned my YouTube playlists into a searchable Obsidian knowledge base

> My workflow is to keep learning playlists in YouTube and let YouTube Playlist Sync mirror them
> into Obsidian. Each video becomes a note with metadata and a transcript; playlist and root index
> notes make the collection navigable, and later syncs only add new videos. I can then query the
> generated properties with Dataview or connect them to Templater/QuickAdd workflows. The plugin
> uses public YouTube data, so there is no YouTube API key, and AI summaries are opt-in.
>
> Community plugin: <https://obsidian.md/plugins?id=youtube-playlist-sync>

> base. It creates one note per video with title, channel, URLs, IDs, thumbnail, description,
> upload date, category, duration, keywords, and a transcript when captions are available. It
